가이드의 DEC-01~13을 대조해 02~11을 구현 기준으로 채택했다. 단일 정책·고정 버전 구성은 유지하며 공개 권한·격리와 보관 기간·전체 총량은 숫자·방식이 없어 공개 전 결정 항목으로 남겼다. 원격 main 및 열린 PR을 확인한 뒤 feat/dec-upload-validation 브랜치와 PR #2를 만들었다.

업로드·커스텀 삭제·파일 저장·메타데이터·같은 출처 브라우저 요청 검사를 추가했다. 기존 T01~T04 회귀 외에 실제 PostgreSQL·파일·HTTP 크기 경계, 경합, 장애 주입과 브라우저 시험을 구성했다. 초기 로컬 Node API 6개 통과. CI 결과는 TEST_RESULTS와 PR에 기록한다. 실제 악성코드나 개인 파일은 시험에 사용하지 않는다.

실제 시험에서 크기 초과 응답의 연결 끊김을 발견해 Tomcat의 중단 요청 소비 한도를 12 MiB로 맞췄다. 브라우저 경로에서는 Vite의 문자열 프록시가 Host를 바꾸는 동작을 발견해 changeOrigin=false를 명시했다. 보안 검사를 끄거나 실패 검사를 삭제하지 않았다. 서버 24개·Node 6개·재시작·브라우저 5개를 최종 커밋에서 다시 확인한다. 오류 requestId·캐시 제어와 트랜잭션 오류 분류도 맞췄다. 최종 결과는 PR #2의 실행 링크로 남긴다.
